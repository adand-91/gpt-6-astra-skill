# GPT-6 Astra Skill Optimizer v1.0.0

## What it is

An independent, Skill-only audit workflow for GPT-6 Astra. It jointly audits one selected project
and its explicitly related Skills, then proposes evidence-backed improvements.

## Included

- Official-source register for GPT-6 Astra model guidance, Skills, and plugin review rules.
- Audits for initiative, focused clarification, instruction priority, output format, delegation,
  verification, context, authority, security, and maintenance.
- Fact/inference/unknown separation and a structured finding schema.
- Read-only-by-default behavior with an exact path allowlist before authorized edits.
- Five positive and five negative/boundary release-candidate cases.

## Evidence and limits

Sources are retrieved guidance and audit evidence, not model-training data. The Skill does not train
or modify GPT-6 Astra and cannot prove project quality, profitability, release approval, or safety.
Open-ended Skill enumeration, private evidence exposure, installation, publication, and external
messaging remain separately authorized actions.
