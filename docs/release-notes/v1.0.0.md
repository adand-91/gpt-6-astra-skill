# v1.0.0 local stable candidate — bounded evidence, exact handoff, Codex distribution

Date: 2026-08-30. Status: local stable source and distribution candidate; not committed, tagged,
pushed, published, or submitted to a public plugin directory.

## Stable product

Requirement Ledger v1.0.0 has one independent Python CLI/library core and one thin, skills-only
Codex plugin. The core owns bounded input selection, private source packs, explicit candidate
continuity, visible-report validation, exact report/source/state binding, and read-only handoff
verification. The plugin only guides an already-installed compatible core; it contains no MCP,
App, Hook, installer, updater, model runtime, credential, telemetry, or network client.

## Stable workflow

The supported path is `review-init` / `review-check` → `source-pack` / `source-verify` →
`candidate-sync` → final report → `review-bind` → `review-handoff-check`. Audit, daily, and weekly
modes accept only a host/user-selected target, time window, scope root, and explicit files.

Ready means current byte/state identity only. It does not prove truth, authorship, completeness,
quality, approval, or authority to edit, commit, publish, send, schedule, or submit anything.

## Promotion truth

No feature or schema changed after the rebuilt RC passed independent security review. Stable
promotion changes only version/distribution metadata and documentation, then reruns the full local
qualification. Windows-native API tests remain a separate Windows CI requirement because this

Public GitHub release and public Codex plugin submission remain separate maintainer decisions.
