# v0.2.0-beta.1 — useful review cycles

Date: 2026-09-07. Status: published non-latest prerelease; exact-commit CI and public asset re-download checks passed.

## User-visible increment

The installed `review-init` command now creates private, analysis-only scaffolds for `audit`,
`daily`, and `weekly`. Daily and weekly modes can calculate the most recently completed local
window from an explicit IANA timezone, offset-aware `--at` timestamp, and `--boundary-hour`.
Supplying an explicit `--start` and `--end` remains supported for every mode.

## Meaningful safety improvement

- The output is still zero-source: the command reads no history and starts no network client.
- Scaffolds are no-overwrite private files and pass the same `review-check` contract.
- DST gaps advance to the first valid local minute; repeated local times choose the first
  occurrence. Both behaviours are frozen by tests.
- Invalid or conflicting windows, timezones, reference times, and boundary hours fail before an
  output is created.

## Compatibility

The legacy audit builder and `WROTE_PRIVATE_AUDIT_SCAFFOLD` marker remain compatible. v0.1 and
Alpha 3 commands and schemas are unchanged. This candidate does not discover Codex history,
schedule a recurring review, authorise implementation, or perform an external action.
