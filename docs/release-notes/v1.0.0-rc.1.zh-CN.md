# v1.0.0-rc.1 本地候选——准确复盘交接

日期：2026-08-30。状态：仅本地 RC 候选；没有 commit、Tag、push、公开发布或提交插件目录。

## 用户可见增量

RC 1 闭合显式复盘链路。`review-bind` 把一份机械校验有效的 final 报告绑定到其准确 UTF-8
字节、目标摘要、已验证 `source-pack/v1` 与有效 `candidate-ledger/v1`。只读
`review-handoff-check` 会重新打开同一组显式输入，只有当前身份仍一致时才返回
`REVIEW_HANDOFF_IDENTITY_READY`。

不完整证据默认被阻断。`--allow-incomplete-archive` 只允许显式不完整的身份归档，绝不等于实施
交接。所有成功标记仍明确写出 `authority_granted=no` 与 `execution=no`。

## RC 安全收口

- 产物时间戳使用规范形式并进入完整性头；
- 全部来源与报告描述符会一直持有到绑定或交接比较完成；
- 同文件原地变化、目标不匹配、过期 candidate head、HTML 注释／代码围栏伪造正文（包括列表或
  引用容器内的围栏）、未知 frontmatter 控制字段，以及超出持久化上限的 candidate 状态都会
  失败即停；
- 即使进程环境改变，真实账号主目录仍不能作为范围根；
- 输出创建在可用平台使用父目录绑定的相对原语；没有安全原语时失败即停。Windows 现已采用相对
  父 `HANDLE` 创建、受保护 DACL、delete-pending 提交、同身份域父目录复验和纯 HANDLE 回滚。
  本 macOS 候选明确没有运行 Windows 原生 API 测试，后续必须在 Windows CI runner 执行。
