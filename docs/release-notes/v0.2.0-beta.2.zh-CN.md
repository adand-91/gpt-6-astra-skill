# v0.2.0-beta.2 本地候选——延续性与 Codex 分发

日期：2026-08-30。状态：仅本地候选；没有 commit、Tag、push、Release 或提交插件目录。

## 用户可见增量

Beta 2 把两个承诺变成机械校验：未解决的优化候选项不会在跨轮复盘时静默消失；选中的来源字节
在再次使用前不能悄悄变化。同时首次加入面向已安装 CLI 的仓库内 Codex 插件分发。

新增命令：

- `candidate-sync` 使用准确不透明 ID 和前一状态头，创建私有 `candidate-ledger/v1` 状态；
- `source-pack` 从明确范围文件创建不含路径的私有来源绑定；
- `source-verify` 重新打开这些准确文件，只读核对当前字节身份。

## 插件形状

仓库加入 `.agents/plugins/marketplace.json` 与纯 Skill 的 `plugins/requirement-ledger` 包。
插件只有一个聚焦工作流 Skill，不含 MCP、App、Hook、Python 源码副本、安装器或更新器；它先预检
CLI，缺失或版本不兼容时停止。

## 限制

候选 ID 由宿主提供并精确匹配；Beta 2 不做语义去重。来源摘要不证明事实、作者、完整性、隐私审查
或授权。插件已在本地完成脚手架、校验、安装、列出、删除和 marketplace 清理；公开提交仍是维护者
以后单独授权的动作。
