# v1.0.0-rc.1 local candidate — exact review handoff

Date: 2026-08-30. Status: local release candidate only; not committed, tagged, pushed,
published, or submitted to a plugin directory.

## User-visible increment

RC 1 closes the explicit review loop. `review-bind` binds one mechanically valid final report to
its exact UTF-8 bytes, target digest, verified `source-pack/v1`, and validated
`candidate-ledger/v1`. Read-only `review-handoff-check` reopens the same explicit inputs and
returns `REVIEW_HANDOFF_IDENTITY_READY` only when their current identities still agree.

Incomplete evidence is blocked by default. `--allow-incomplete-archive` permits an explicitly
incomplete identity archive, never an implementation handoff. Every success marker still says
`authority_granted=no` and `execution=no`.

## RC security closure

- artifact timestamps are canonical and included in integrity heads;
- all source and report descriptors remain open through binding or handoff comparison;
- in-place changes, target mismatches, stale candidate heads, invisible comment/fence bodies
  (including fences nested in list or blockquote containers), unknown frontmatter control fields,
  and oversized persisted candidate state fail closed;
- the real account home remains forbidden even if the process environment changes; and
- safe output creation uses relative parent binding where supported and fails closed when a secure
  primitive is unavailable. Windows now uses parent-`HANDLE`-relative creation, a protected DACL,
  delete-pending commit, same-domain parent revalidation, and handle-only rollback. Its native API
  tests remain explicitly unexecuted on this macOS candidate and must run on a Windows CI runner.

## Distribution and compatibility

The Python CLI remains the only runtime implementation. The repository-local Codex plugin is a
thin skills-only guide for `requirement-ledger>=1.0.0rc1,<2`; it contains no MCP server, app,
hooks, copied Python runtime, installer, updater, authentication flow, or external action.

## Limits

Identity hashes do not prove truth, authorship, completeness, privacy clearance, or authority.
The CLI does not discover all Codex history and does not edit, commit, push, publish, or message.
Public release and public plugin submission remain separate maintainer decisions.
