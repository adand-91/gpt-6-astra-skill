# Astra Skill Doctor v1.0.0

## 产品定位

独立的、仅由 Skill 构成的 GPT-6 Astra 适配审计流程。它联合审计一个选定项目及其明确关联的
Skill，再提出有证据依据的优化方案。

## 本版内容

- GPT-6 Astra 模型指南、Skills 文档和插件审核规则的官方来源登记。
- 主动推进、聚焦澄清、指令优先级、汇报格式、委派、验证、上下文、授权、安全和维护审计。
- 事实／推断／未知区分及结构化问题字段。
- 默认只读；获得授权修改前必须列出精确路径白名单。
- 五个正向和五个负向／边界候选验收场景。

## 证据与边界

来源是可追溯的官方指导和审计证据，不是模型训练数据。本 Skill 不训练或修改 GPT-6 Astra，也不能
证明项目质量、盈利、发布批准或安全性。开放式扫描 Skill、暴露私有证据、安装、发布和外部消息仍需
单独授权。
