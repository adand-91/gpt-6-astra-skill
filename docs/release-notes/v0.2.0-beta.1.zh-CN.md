# v0.2.0-beta.1 预发布候选——可用的复盘周期

日期：2026-09-07。状态：预发布候选；公开发布须以精确提交通过 CI 为前提。

## 用户可见增量

安装后的 `review-init` 现在能创建 `audit`、`daily`、`weekly` 三种私有、仅分析骨架。
Daily／weekly 可根据明确 IANA 时区、带偏移的 `--at` 参考时刻和 `--boundary-hour`，
计算最近已经完成的本地窗口。三种模式仍都支持明确传入 `--start` 和 `--end`。

## 有实际价值的安全改进

- 输出仍为零来源：命令不读取历史，也不启动网络客户端。
- 骨架仍为禁止覆盖的私有文件，并通过同一个 `review-check` 契约。
- 夏令时缺口顺延到第一个有效本地分钟；重复本地时间选择第一次出现，两种行为都有冻结测试。
- 非法或冲突的窗口、时区、参考时刻和边界小时会在创建输出前失败。

## 兼容性

旧 audit builder 与 `WROTE_PRIVATE_AUDIT_SCAFFOLD` 标记保持兼容；v0.1 和 Alpha 3 命令／
schema 不变。本候选不会发现 Codex 历史、创建定时复盘、授权实施或执行外部动作。
