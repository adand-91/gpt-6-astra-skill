# v0.2.0-beta.2 local candidate — continuity and Codex distribution

Date: 2026-08-30. Status: local candidate only; not committed, tagged, pushed, released, or
submitted to a plugin directory.

## User-visible increment

Beta 2 makes two promises mechanical: unresolved improvement candidates do not silently
disappear between reviews, and selected source bytes cannot silently change before reuse. It also
adds the first repository-local Codex plugin distribution for the already installed CLI.

New commands:

- `candidate-sync` creates a private `candidate-ledger/v1` state from exact opaque IDs and a prior
  head;
- `source-pack` creates a private path-free source binding from explicit scoped files; and
- `source-verify` reopens those exact files and verifies current byte identity without writing.

## Plugin shape

The repository contains `.agents/plugins/marketplace.json` and a skills-only
`plugins/requirement-ledger` package. The plugin has one focused workflow Skill, no MCP, app,
hooks, Python source copy, installer, or updater. It preflights the CLI and stops on a missing or
incompatible version.

## Limits

Candidate IDs are supplied by the host and matched exactly; Beta 2 does not perform semantic
deduplication. Source hashes do not prove truth, authorship, completeness, privacy review, or
authorization. The plugin has been locally scaffolded, validated, installed, listed, removed, and
cleanly unregistered; public submission remains a separate maintainer action.
