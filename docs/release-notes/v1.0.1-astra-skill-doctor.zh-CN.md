## 范围

Astra Skill Doctor 审查一个选定项目及其相关 Skill 是否适配 GPT-6／Astra。它输出证据、过时约束、经授权的最小改动、验证结果和唯一下一步，不宣称模型训练、项目成功或发布批准。
