# Historical scope ledger — v0.1

This file preserves the v0.1 planning record. It is not the active scope authority for the v1
release train. The active product, safety, release, and non-authorisation rules are frozen in
[V1_STABLE_CONTRACT.md](V1_STABLE_CONTRACT.md).

## Historical v0.1 intent

- Turn explicit repository, transcript, Git, and test evidence into a private retrospective,
  conservative repair proposal, and later validation record.
- Keep `unknown` rather than claiming upstream/project/personal attribution without evidence.
- Preserve the original Requirement Ledger workflow while making the package installable,
  deterministic, privacy-aware, and read-only.
- Keep implementation, commit, publication, and external interaction as separately authorized
  host-owned actions.

## Superseded assumptions

The v0.1 planning language about a future host discovering related history is superseded. v1 accepts
only an explicit target/window and explicit selected files; it never discovers all sessions,
projects, or files. Its Codex integration is a thin, skills-only repository plugin over the
independent CLI, not a privileged history daemon or an MCP service.

## Active v1 acceptance boundary

- Local stable means the frozen v1 contract, source/build/install/privacy/plugin checks, and
  recorded local evidence have passed.
- It does **not** mean a tag, push, GitHub Release, public CI run, marketplace submission, external
  promotion, or programme application has occurred.
- Any public or mutating action remains outside this ledger and needs its own current authority.
