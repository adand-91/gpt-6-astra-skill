# v0.1.1 — Requirement Ledger AI discovery and Skill walkthrough

Status: released on 2026-08-28 from commit `d07c13f91b119acf55135a504b8ba993f6b1aaf9`;
public CI run `33159107505` passed before tagging.

## What changed

- The product is now presented as **Requirement Ledger AI**, an AI project and Skill feedback
  loop for Codex, Claude Code, and any Git project.
- README discovery metadata, badges, search terms, and first-use framing now make the two primary
  jobs explicit: improving an agent Skill and improving an ordinary software project.
- A wholly synthetic, reproducible Skill walkthrough demonstrates the complete boundary:
  explicit evidence → conservative analysis → reviewable plan → separately authorised host edit
  → externally run, digest-bound before/after oracle → `improved` validation.
- The new bilingual roadmap defines the fifteen-day technical launch track through `v0.2.0`,
  `v1.0.0-rc.1`, and `v1.0.0`, while keeping autonomous edits and GitHub actions outside v1.
- Package and record versions now share one authoritative `__version__` source.

## Compatibility and safety

- No CLI command, schema, repository slug, package name, or console command changed.
- The CLI still does not discover private histories, execute project code, edit a Skill or
  worktree, install project dependencies, access a network, or perform GitHub/account actions.
- One local conversation and oracle do not establish upstream attribution; the walkthrough's
  issue scope remains `unknown`.
- The Skill edit in the walkthrough belongs to an authorised host such as Codex or Claude Code,
  not to Requirement Ledger itself.
