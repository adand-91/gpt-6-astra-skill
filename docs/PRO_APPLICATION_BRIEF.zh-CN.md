# Astra Skill Optimizer——项目申请简报

## 项目名称

Astra Skill Optimizer

## 仓库

https://github.com/adand-91/gpt-6-astra-skill

## 一句话介绍

一个开源工作流，用证据、最小授权改动和可复核验证，审计并适配项目 Skill 与个人工作流，使其适应 GPT-6／Astra 的行为变化。

## 要解决的问题

新一代模型发布后，旧 Skill 可能变得误导：过度限制模型能力、频繁触发多余澄清、输出错误格式，或无法验证重要结论。用户需要一种实际可用的方法，在不丢失安全边界和项目上下文的情况下发现这些失真并更新 Skill。

## 短期目标

在经过脱敏的选定项目上，找出过时约束和工作流失败，提出最小可回滚的 Skill 修改，并用成功案例和边界案例比较修改前后的行为。

## 长期愿景

建设类似 Jarvis 的个人与开源社区系统，持续维护可复用 Skill：模型兼容性、版本化测试、个人工作流适配、失败回放、有证据的变更历史和安全回滚。

## 当前实现

- 针对一个选定项目及其明确关联 Skill 的独立适配工作流。
- 分开记录事实、推断和未知。
- 默认只读审计，修改需要明确授权。
- 保留旧 Python 证据组件和 CLI 作为兼容入口。
- 公开产品显示名为 Astra Skill Optimizer。

## 当前验证

- 在文档说明的 macOS 边界下，测试共 213 项，206 项通过、7 项跳过。
- 插件结构校验通过。
- 翻译同步、交接校验和空白差异检查通过。
- `1.0.2` Astra Skill Optimizer 已推送到默认分支，尚未新建标签或 GitHub Release。

## 额外模型访问的用途

更高能力的模型环境将帮助我们在更复杂、更含糊和多步骤的 Skill 失败上评估同一套审计流程，比较新增约束是否同时保留主动性与安全性，并产出更清晰、可复现的开源示例。访问权限只用于项目研究、Skill 评估和文档整理，不用于交易、客户工作、凭据处理或无人值守外部动作。

## 开源贡献计划

- 发布兼容性契约和聚焦的审计工作流。
- 增加脱敏失败案例和回归测试。
- 明确记录已核实、推断、跳过和未知内容。
- 接受范围清楚、带可复现测试的社区案例与改进。
