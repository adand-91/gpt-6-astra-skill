# Support

For usage questions, installation help, and feature discussion, use the repository’s GitHub
Discussions area when it is available. For reproducible defects, use the bug-report form.

Before asking for help, remove all real transcripts, secrets, tokens, cookies, authorization
headers, private remote URLs, customer identifiers, session IDs, and absolute personal paths.
Use a small synthetic example instead.

Support can explain how to inspect local evidence and drafts, but it cannot approve sharing or
applying an action on your behalf. Feedback remains `DRAFT — NOT SENT`, and local actions are
never automatically applied, committed, pushed, or sent externally.
