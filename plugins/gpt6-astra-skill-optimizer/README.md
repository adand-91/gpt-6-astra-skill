# Astra Skill Optimizer

A focused workflow for adapting project Skills and personal workflows to GPT-6/Astra behavior.

It jointly audits one selected project and its explicitly related Skills. It uses versioned
official-source evidence, separates facts from inferences and unknowns, and is read-only by
default. Explicit authorization is required before changing Skill files, and publication remains
a separate action.

## First use

Install the plugin from this repository's `plugins/gpt6-astra-skill-optimizer` directory, select
one project, and say:

> 请审计一下我们目前的项目和相关 Skill，看看有没有需要优化的。

The first report contains the project audit, Skill audit, official-source boundaries, one
recommended change, and its acceptance test. The workflow does not train GPT-6 Astra or guarantee project results.

## Scope

The packaged workflow covers triggers, initiative, focused clarification, instruction priority,
format, tool/delegation guidance, verification, context, authority, security, and maintenance.
It does not enumerate arbitrary Skills, expose private evidence, install dependencies, publish,
send messages, or trade without separate authority.
