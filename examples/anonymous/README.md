# Anonymous example

These files are wholly synthetic. They contain no copied user conversation, repository path,
session identifier, credential, remote, customer name, or private error output.

For the fastest demonstration, use the installed command:

```bash
requirement-ledger demo --output-dir /tmp/requirement-ledger-demo
```

To exercise the real scanner, point `--repo` at a disposable Git fixture and pass
`transcript.md` and `test.log` explicitly. The new CLI will never search your home directory.
